## 이 판에서 바뀐 것 (0.5.23 → 0.5.32)

고양이
- 1Key 창을 열어 두어도 고양이가 그대로 있다.
- 끌어서 옮기기: 높은 곳에 놓으면 천천히 떨어져 착지하고, 작업 표시줄에 놓은 자리가 새 집이 된다(다음에 켜도 그 자리).
- 다른 창 위에 앉기: 놓은 자리 아래에 보이는 창의 윗변에 착지해 그 창 폭 안에서 논다. 창이 비활성이 돼도 그대로, 창을 옮기면 같이, 창이 최소화 · 최대화 · 닫힘 · 숨김이 되거나 앉은 자리가 덮이면 아래로 떨어진다. 창 위 자리는 저장하지 않는다.
- 떨어지는 동안(공중)은 고양이가 누름을 통과시켜 아래 창의 단추가 눌린다. 발이 닿으면 다시 누를 수 있다.
- 1Key 창 · 상자 · 입력 칩 · 잠금 위젯과 겹치면 고양이는 보이되 누름을 통과시킨다(아래 1Key 단추 · 입력칸 보호).
- 좌클릭에도 이름 · 단계 · 하트 딱지.
- 깜짝 놀잇감: 누를 수 있는 동안 반짝임(빛무리 + 깜빡이는 고리)과 "눌러서 같이 놀아요" 말풍선(5초마다), 그동안 고양이를 눌러도 1Key 창 대신 같이 논다.
- 위젯 화면: 목록 아래 [위젯] — 상태 · 단계 · 같이 놀기 · 오늘의 미션 · 앨범 · 흰/검은 고양이 이름(설정에서 옮김). 고양이 메뉴 [수첩]도 이 화면을 연다(잠겨 있으면 예전 수첩 상자).
- 수첩 · 안내 상자는 한 번에 하나. 미션 이름 "내 항목 비밀번호" · "마스터 비밀번호".
- 점수: 지금 테마의 고양이만 줄고, 쉬는 테마의 고양이는 기다린다. 로그인 항목의 비밀번호(두 번째 칸)를 바꿔도 보상.
- 정시 시계 · 끌기 · 착지 · 메뉴가 서로 끼어들 때의 처리(끌면 시계를 닫음, 누르는 동안 새 하트 · 도장 미룸, 떨어지는 동안 메뉴 없음, 그림 준비 실패 · 동작 창 그림 실패 때 바로 앉고 누름 통과 해제).

## 검증 요약

- 자체 검사(창 없음) siteunit 252/252 — 새 PC01(창 위에서 걷는 중 · 떨어지는 중의 실제 자리, 덮임, 창이 좁아질 때 남은 걸음 계산).
- 창 시험(이 PC, 사용자가 PC 를 쓰지 않을 때, 실제 마우스는 사용자 허락 뒤에만):
  - 최종 exe(`AF2F7771…`): startup, perch 18/18(다른 창 위에 앉기 · 떨어지기 · 덮임 · 창 상태 · 시계 · 공중 재낙하 · 누름 통과 · 1Key 창과 겹친 착지), catdrag 11/11(실제 마우스 끌기 · 착지 · 겹침).
  - 0.5.31(`7AE13F53…`): cattoy 4/4(놀잇감 말풍선 · 고양이 클릭 놀이), widget 7/7. 0.5.29: catenv · catseq · catwalk · catpeek · cattheme. 그 뒤 앱 변경은 해당 묶음과 관계없는 범위라 이 결과를 근거로 쓴다.
  - **모든 시험이 처음부터 통과한 것은 아니다.** 시험 스크립트 탓 실패(타이밍 · 시험 창 최소 폭 · 이 PC 의 다른 프로그램 창 · 사용자 1Key 가 켜져 있음)와 사용자 입력으로 멈춘 실행이 있었고, 고친 뒤 다시 돌렸다. 원본 기록은 docs/test-logs 에 그대로 둔다. 모든 시험이 하나의 exe 로 돌아간 것도 아니다(위 해시별).
- 설치 확인: 이 PC 에서 설치 시 Defender · SmartScreen 경고 없음, 설치된 `1Key.exe` 해시가 위 표와 같다. 사용자가 창 위 착지 · 창 닫힘 낙하 · 놀잇감 반짝임/말풍선/고양이 클릭 · 1Key 창과 겹칠 때 보임과 아래 단추 눌림을 확인했다.

## 알려진 제한 · 후속

- 주 모니터 · 아래 작업 표시줄만. 다른 모니터의 창에는 앉지 않는다.
- 창 윗변은 DWM 의 보이는 테두리 기준이다. 투명하지만 누름을 받는 큰 창은 덮개로 칠 수 있다.
- 1Key 창과 겹친 동안에는 고양이를 누르거나 끌 수 없다.
- 끌어 놓은 집 위치는 작업 영역 폭의 비율로 저장한다(해상도 · 배율이 바뀌면 같은 픽셀이 아닐 수 있음). 예전 판으로 되돌려 고양이 기록을 저장하면 집 위치 줄이 사라진다.
- 검은 고양이는 정지 그림과 동작 그림의 색 · 얼굴이 다르게 보이는 구간이 있다(동작 다시 칠하기 진행 중).
- 실제 로그인 때 자동 실행 확인, 고양이 기록 저장의 몇 가지 동기 저장 등 0.5.23 의 후속은 그대로다.
- 보안 프로그램 판정은 PC 와 시점에 따라 다를 수 있다. 무경고는 이 PC 에서 관찰한 결과다.

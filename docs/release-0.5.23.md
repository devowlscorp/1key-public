## 이 판에서 바뀐 것

- 화면 구성이 바뀌거나 작업 표시줄이 다시 만들어진 뒤에는 작업 영역 · 배율 · 색이 같아도 고양이를 다시 배치한다.
- 일반 설정 변경 알림으로 고양이 동작이 끊기지 않도록, 바뀐 게 없으면 다시 배치하지 않는 기존 처리는 유지한다.
- 고친 파일: `CatWidget.cs`, `AppWndProc.cs`, 버전 표기(`App.cs`, `OneKey.csproj`).

## 검증 요약

이 판에서 새로 한 것:
- 자체 검사(창 없음) 250/250.
  - 처음 두 번은 "30 초 안에 끝나지 않음"으로 실패했다. 0.5.22 exe 도 같은 시점에 똑같이 실패했다.
  - 그 뒤로는 20 초에 끝나고 통과했다. 원인은 확정하지 않았다.
- 고양이 창 시험 다섯 묶음(시작 · 동작 순서 · 걷기 · 빼꼼 · 테마) 통과.
  - 첫 시도는 사용자 입력이 감지돼 시작 직후 멈췄고, 다시 돌려 통과했다.
- 신호 확인 시험(`tools/tests/catenv.ps1`) 5/5:
  - 일반 설정 변경 알림: 다시 그리지 않음.
  - 화면 구성 변경 · 작업 표시줄 다시 만들어짐: 다시 배치하고, 표시 횟수가 늘고, 다시 보임.
  - 수정 전 0.5.22 로 같은 시험을 돌리면 이 항목들이 실패한다.
  - 첫 실행은 시험 스크립트의 버그(함수 이름이 PowerShell 별칭에 가려짐)로 0/5 였고, 고친 뒤 통과했다.
  - 실제 해상도 변경 · 탐색기 재시작은 하지 않았다. 시험용 1Key 창에 메시지만 보냈다.
- 설치 확인: 이 PC 에서 설치 시 Defender · SmartScreen 경고가 없었고, 설치된 `1Key.exe` 해시가 위 표와 같다.

0.5.22 에서 가져온 근거:
- 위 변경이 닿지 않는 영역(설정 · 바로 실행 · 웹 즐겨찾기 · 백업 · 자동 실행 등)의 시험과 실측은 0.5.22 의 것을 그대로 근거로 쓴다.
- 이 판에서 그 묶음들을 다시 돌리지는 않았다.

## 알려진 제한 · 후속

- 실제로 다시 로그인했을 때 자동 실행이 1Key 를 띄우는지는 아직 확인하지 않았다.
- 고양이 기록의 종료 때 저장은 최선의 시도이며 저장 성공을 보장하지 않는다.
- 잠글 때 위젯 위치 저장, 위젯을 끌어 옮긴 뒤의 저장, 예전 형식 설정 파일의 변환 저장은 아직 화면 스레드에서 한다.
- 설정 파일 크기 상한, 일부 확장 측정은 후속이다.
- 실제 모든 모니터 · 배율 · 탐색기 상태에서의 다시 배치를 보장하지는 않는다.
- 보안 프로그램(Defender · SmartScreen)의 판정은 PC 와 시점에 따라 다를 수 있다. 이 판의 무경고는 이 PC 에서 관찰한 결과다.

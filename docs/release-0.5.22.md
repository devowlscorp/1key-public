## 이 판에 들어간 것

- 금속 디자인의 모든 화면, 밝은 테마(흰 고양이)와 어두운 테마(검은 고양이).
- 작업 표시줄 고양이: 걷기 · 쉬기 · 정시 알림 시계, 오른쪽 클릭 메뉴(쓰담 · 츄르 · 놀이 · 수첩 · 열기 · 잠금 · 설정 · 숨기기), 자라는 고양이, 출근 도장, 쉬는 시간 친구, 깜짝 놀잇감, 고양이 수첩과 앨범.
- 잠금 위젯의 고양이.
- 설정의 후원 화면: 데브아울스 후원 페이지(`https://devowls.kr/donate`) QR · 브라우저 열기, GitHub 별 주기, 제휴 링크(한국어 화면, 경제적 이해관계 문구를 먼저 보임). 후원하지 않아도 모든 기능은 같다.
- 출시 전 점검에서 고친 것:
  - 화면 바꾸기가 한 번에 그려진다(설정 화면 아래쪽이 늦게 나타나던 문제).
  - 잠금 해제 직후 고양이 기록 저장이 화면을 기다리게 하지 않는다(일부 실행 파일에서 잠금 해제가 0.4 초쯤 늦던 문제 — 같은 저장 경로의 지연이 실행 파일에 따라 달랐다는 관찰이며, 보안 프로그램 원인설은 확정이 아니다).
  - 자동 실행을 바꾸다 관리자 승인(UAC)을 취소하거나 일부만 바뀌면, "자동 실행" · "항상 관리자 권한으로 실행" 설정을 실제 등록에 맞춰 되돌리고 남은 등록을 알린다. 등록을 확인하지 못하면 성공으로 보지 않는다. 잠겨 있으면 잠금을 푼 뒤에 되돌린다.
  - 원격 접속 프로그램이 켜져 있어도 프로그램 바로 실행이 막히지 않는다.
  - 웹 아이콘 저장은 연결 폴더를 따라가지 않는다.

## 검증 요약

- 자체 검사(창 없음) 250/250.
- 창 시험: 앞선 후보의 전체 통합 회차에 이후 변경분의 시험을 더했다 — 시작 · 바로 실행 · 웹 즐겨찾기 · 설정 화면 · 테마 · 언어 · 접근성 · 고양이 · 후원 화면 · 자동 실행 실패 처리(AF01–AF06) 등. 후보 8 에서 모든 묶음을 한 번에 다시 돌린 것은 아니다.
- 실제 PC 실측: 설치(Defender · SmartScreen 경고 없음 — 이 PC, 이 설치), 실제 모니터에서 설정 진입, 자동 실행 보통 ↔ 관리자 전환 · UAC 취소 · 끄기 · 실제 제거 · 다시 설치 · 원래 상태로 복구.

## 알려진 제한 · 후속

- 실제로 다시 로그인했을 때 자동 실행이 1Key 를 띄우는지는 아직 확인하지 않았다. 자동 실행 계획의 일부 실측(바꾸는 중 종료 · 부모 강제 종료 · 다른 대상 보존)도 실제 환경에서는 하지 않았다.
- 고양이 기록의 종료 때 저장은 최선의 시도이며 저장 성공을 보장하지 않는다.
- 잠글 때 위젯 위치 저장, 위젯을 끌어 옮긴 뒤의 저장, 예전 형식 설정 파일의 변환 저장은 아직 화면 스레드에서 한다.
- 설정 파일 크기 상한, 일부 확장 측정은 후속이다.
- 보안 프로그램(Defender · SmartScreen)의 판정은 PC 와 시점에 따라 다를 수 있다 — 이 판의 무경고는 이 PC 의 관찰이다.

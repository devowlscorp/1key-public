# work/

Local working folder for the public edition: artwork sources, mascot drafts, video and frame-interpolation work files,
design review notes and the task list.

Only this README is tracked. Everything else under `work/` is listed in `.gitignore` and stays on the local machine —
large image and video sources, notes and scripts that are not meant to be published.

The app's finished assets live in `src/OneKey/Assets/` and are built by the tools in `tools/`.
